## 2. Detailed Finding-by-Finding Remediation Record

### H3-01: Configuration Shadowing in Detector Configuration
- **ID**: `FINDING-H3-01`
- **Original Problem**: Ambiguity between top-level `config.detector` and nested `config.perception.detector`. `DroneTracker` read `config.detector.use_yolo`, ignoring overrides specified under `perception.detector.use_yolo` in `config/default.yaml`.
- **Root Cause**: During V2 perception modularization, `PerceptionConfig` was created with `detector: DetectorConfig`, while `SkyVantaConfig` retained a top-level field `detector: DetectorConfig` for V1 scripts.
- **Files Changed**:
  - `skyvanta/core/config.py`: Converted `config.detector` from a duplicate model field to a bidirectional `@property` getter/setter routing to `config.perception.detector`. Added `@model_validator(mode="before")` to automatically migrate legacy dictionaries containing top-level `detector` into `perception.detector`.
  - `skyvanta/tracking/tracker.py`: Standardized all access on `self.config.perception.detector.use_yolo`.
  - `skyvanta/cli.py`: Updated CLI flags (`--yolo`, `--no-yolo`) to mutate `config.perception.detector.use_yolo`.
  - `skyvanta/pipeline/runner.py`: Standardized on `config.perception.detector`.
- **Tests Added/Modified**:
  - `tests/unit/test_config_shadowing.py`: Added 5 targeted regression tests verifying authoritative consumption, property bidirectional sync, legacy dictionary migration, conflict resolution priority, and non-duplicate YAML serialization.
- **Targeted Test Result**: 5 PASSED (0.05s)
- **Full Regression Result**: 261 PASSED (9.45s)
- **Risk**: None. Backward-compatible properties maintain compatibility with external or legacy scripts accessing `.detector`.
- **Final Status**: **RESOLVED**

### H3-02: YOLO Runtime Network / Weights Hardening
- **ID**: `FINDING-H3-02`
- **Original Problem**: `YoloDroneDetector` could implicitly trigger network downloads of model weights from external servers when weights were missing locally.
- **Root Cause**: Ultralytics' `YOLO(model_name)` defaults to auto-downloading weights from GitHub releases if the file is not found in the local cache directory.
- **Files Changed**:
  - `skyvanta/core/config.py`: Added `allow_network_download: bool = Field(default=False)` to `DetectorConfig`.
  - `config/default.yaml`: Explicitly configured `allow_network_download: false`.
  - `skyvanta/perception/detection/yolo.py`: Enforced explicit local file verification before initializing the YOLO engine. If the weights file is missing and `allow_network_download` is `False`, the detector immediately logs a warning and falls back to motion contrast detection (or raises `ModelLoadError` if `strict=True`).
- **Tests Added/Modified**:
  - `tests/unit/test_yolo_hardening.py`: Added 4 targeted tests verifying disabled config handling, strict missing-model exception raising, graceful fallback in default mode, and zero network downloads.
- **Targeted Test Result**: 4 PASSED (0.04s)
- **Full Regression Result**: 261 PASSED (9.45s)
- **Risk**: None. Ensures deterministic, offline execution in air-gapped robotics test environments.
- **Final Status**: **RESOLVED**

### H3-04: Coordinate Metadata ENU/NED Consistency
- **ID**: `FINDING-H3-04`
- **Original Problem**: `STANDARD_FRAMES[FrameId.WORLD]` metadata declared `convention="NED"`, while the simulation dynamics, state propagation, and digital twin kinematics operate in an **East-North-Up (ENU)** Cartesian coordinate system ($+Z$ Up / Altitude $\ge 0$).
- **Root Cause**: Historical draft comment in `frames.py` was not updated when ENU was adopted as the simulation world standard in V5/V6/V9.
- **Files Changed**:
  - `skyvanta/spatial/frames.py`: Updated `FrameDefinition` for `FrameId.WORLD` to formally specify `convention="ENU"`, `+X: East`, `+Y: North`, `+Z: Up (Altitude)`.
  - `skyvanta/spatial/transform.py`: Added explicit, vectorized conversion functions between ENU and NED: `enu_to_ned_position`, `ned_to_enu_position`, `enu_to_ned_velocity`, `ned_to_enu_velocity`, `enu_to_ned_rotation`, `ned_to_enu_rotation`.
  - `skyvanta/spatial/__init__.py`: Exported all conversion functions.
  - `docs/architecture/v5-coordinate-frame-graph.md`: Documented authoritative ENU simulation world convention and explicit NED conversions.
- **Tests Added/Modified**:
  - `tests/unit/test_coordinate_conventions.py`: Added 4 tests verifying FrameId metadata, position conversions, velocity conversions, and rotation matrix roundtrip invariants.
- **Targeted Test Result**: 4 PASSED (0.04s)
- **Full Regression Result**: 261 PASSED (9.45s)
- **Risk**: None.
- **Final Status**: **RESOLVED**
