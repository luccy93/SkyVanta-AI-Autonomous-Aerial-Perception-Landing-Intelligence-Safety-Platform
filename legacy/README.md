# Legacy Prototype Archive

This directory preserves the original monolithic prototype implementations of the Drone Landing Perception System.

## Contents
* `legacy/main.py`: Original 1,286-line Python pipeline.
* `legacy/main.cpp`: Original 175-line C++ Kalman bouncing ball demo.

## Running the Legacy Prototype
To run the legacy Python prototype:
```bash
python legacy/main.py [optional_video.mp4]
```
If no video file is provided, it runs in synthetic demonstration mode.
